## ✅ Tasks Completed

### 🌸 Task 1 — Iris Flower Classification
- **Objective:** Classify Iris flowers into 3 species based on measurements
- **Dataset:** Iris Dataset (150 samples, 4 features)
- **Model:** Logistic Regression
- **Accuracy:** 100% ✨
- **Tools:** Python, Scikit-learn, Pandas, Matplotlib, Seaborn

### 🏠 Task 2 — House Price Prediction
- **Objective:** Predict house prices based on various features
- **Dataset:** California Housing Dataset (20,640 samples)
- **Model:** Linear Regression
- **R2 Score:** 0.5758 (57.58%)
- **Tools:** Python, Scikit-learn, Pandas, Matplotlib, Seaborn

### 🚢 Task 3 — Titanic Survival Prediction
- **Objective:** Predict survival of Titanic passengers
- **Dataset:** Titanic Dataset (891 passengers)
- **Model:** Logistic Regression
- **Accuracy:** 80% 🎯
- **Tools:** Python, Scikit-learn, Pandas, Matplotlib, Seaborn
